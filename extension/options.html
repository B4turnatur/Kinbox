Kinbox

1. Mit deinem Server verbinden

Die Adresse und den Token zeigt start.bat beim Start auf dem Server an (Token steht auch in settings.json).

2. Server (nur Admin)

Profile für die Familie verwaltest du in der Mediathek → ⚙ → Familie.

YouTube ändert oft etwas – wenn Downloads plötzlich scheitern, hilft meist ein Update.

Automatisch aufräumen

Gilt nur für deine Dateien. Jederzeit umschaltbar und frei kombinierbar. Gelöscht werden nur Dateien, die Kinbox selbst geladen hat – und nie welche, die du in der Mediathek mit 📌 markiert hast.

Nachts laden

Downloads mit „Nachts" starten erst in diesem Zeitfenster (gilt für die ganze Familie).

3. Verhalten

Tastenkürzel: Alt+Shift+D Popup · Alt+Shift+Q sofort laden · Alt+Shift+M als MP3. Ändern

4. Aussehen

5. Presets

Eigene Presets legst du im Popup über „★ Als Preset" an. Dort kannst du sie auch als Standard festlegen.

Nur im Heimnetz nutzen – den Port nicht im Router freigeben. Für unterwegs lieber VPN (z. B. WireGuard/Tailscale).
